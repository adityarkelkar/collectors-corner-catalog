# Collectors Corner catalog

Card catalog files for one personal, undistributed build of the Collectors Corner app.

- `manifest.json` names the current catalog version, its file, size and SHA-256 checksum.
- `catalog-<version>.json` holds TCGdex's public English card text, without prices or images.
- `LICENSE-TCGdex.txt` is the MIT license of the TCGdex card database the catalog is built from.

Card data from [TCGdex](https://tcgdex.dev), MIT License, Copyright (c) 2021 TCGdex. No images, collection data or personal data are published here.
